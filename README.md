# Bandora — IELTS Learning Platform

A calm, focused IELTS preparation platform built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**.

## Project Structure

```text
├── frontend/             # Next.js + TypeScript + Tailwind CSS web app
├── Backend/              # Backend services (upcoming)
└── Aditional-Document/   # Project documentation & assets
```

## Getting Started (Frontend)

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Scripts

- `npm run dev` — Start development server
- `npm run lint` — Run ESLint
- `npm run build` — Create production build
